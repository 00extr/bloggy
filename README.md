## Использование AI 

При работе над проектом использовались ИИ-ассистенты (в качестве справочника и инструмента автоматизации)

1. **Конфигурация окружения и сборки** 
Настройка CLI-скриптов для компиляции Dart Sass (`package.json`) для быстрой интеграции SCSS в чистый PHP-проект.

2. **Генерация фикстур (Сидер)** Написание массивов тестовых данных со случайными заголовками и текстами для сидера базы данных, чтобы не тратить время на ручной копипаст "Lorem Ipsum".

3. **Ревью кода** Проверка написанных SQL-запросов и контроллеров на соответствие стандартам PSR, отсутствие явных уязвимостей и синтаксических опечаток.

**Вся ключевая бизнес-логика спроектирована и написана самостоятельно**

**Конфигурация:** 
Для простоты ( в рамках ТЗ ) доступы к БД оставлены в конфиге класса Database. На реальном продакшене пароли, ключи  должны быть вынесены в переменные окружения.
